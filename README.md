# Queen's Domain 한글 패치

이 저장소는 Windows용 한글 패치의 설치·복구 및 제작 도구 소스를 제공합니다. 패치 데이터는 Releases의 ZIP으로 제공합니다.

## 적용 대상 Steam 빌드

- **Steam build ID: `26356968`**
- 게임 내부 `version.txt`: `13480`
- Windows 11, 기본 Windows PowerShell 5.1
- 패치 파일: `queens-domain-ko-26356968.zip`

설치기는 대상 게임 파일의 해시가 일치할 때만 설치합니다. 게임이 업데이트되면 이 패치가 적용되지 않을 수 있습니다.

## 마지막 Releases 이후 패치 업데이트

게임 버전 13480 / Steam build 26356968에 대응합니다. 게임 업데이트로 바뀐 도전 메뉴의 확인 문구 키에 기존 한국어 번역을 연결했습니다. 기존 영어 현지화 항목과 패치 대상 원본 리소스의 변경 여부도 대조했습니다.

Linux의 독립 사본에서 설치 → 복구·백업 정리 → 재설치를 확인했습니다. **13480 Windows 설치·복구는 시험 환경의 CMD 실행 오류로 미실행이며, 실게임 표시와 글꼴도 확인하지 않았습니다.** 전체 게임 QA를 완료한 릴리스는 아닙니다.

## 설치 방법

1. Releases에서 `queens-domain-ko-26356968.zip`을 내려받습니다.
2. 게임과 Steam 업데이트, 모드 관리자 등 게임 파일을 변경할 수 있는 프로그램을 종료합니다.
3. ZIP 안의 `KoreanPatch` 폴더를 게임 설치 폴더에 넣습니다. `version.txt`와 `KoreanPatch`가 같은 위치에 있어야 합니다.
4. `KoreanPatch/install.cmd`를 실행하고 안내를 확인한 뒤 진행합니다. 설치가 끝날 때까지 창을 닫거나 PC를 끄지 마세요.
5. 게임의 언어 설정에서 **일본어**를 선택합니다. 이 슬롯의 일본어는 한국어로 대체되며 일부 공통 이미지와 위젯은 다른 언어에도 영향을 줄 수 있습니다.

이전 패치가 설치돼 있다면 이전 버전의 `KoreanPatch/restore.cmd`로 먼저 복구하세요. 패치를 제거하려면 현재 패치의 `restore.cmd`를 실행하고 복구가 끝날 때까지 기다립니다. 복구가 끝나기 전에 백업이나 상태 파일을 직접 지우지 마세요.

## 소스와 재현 범위

**이 저장소의 소스 파일만으로는 완성된 한글 패치를 재현할 수 없습니다.** 게임 원본 텍스트·이미지와 번역·수정된 리소스 및 패치 PAK는 소스 저장소에 포함하지 않습니다. 해당 자료와 별도의 Unreal 리소스 도구가 필요합니다. Releases ZIP에는 설치에 필요한 패치 데이터가 들어 있습니다.

`scripts/build_package.py`는 별도로 준비한 정확한 패치 PAK와 이 저장소의 설치기·manifest·안내문으로 ZIP을 조립합니다. 제작 소스는 `project/tools/`, 공통 텍스트 검사의 의존 코드는 `toolbox/tools/`에 있습니다. UAssetAPI와 UnrealLocres 등 외부 실행 파일은 제공하지 않습니다.
