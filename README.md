# Queen's Domain 한글 패치

이 저장소는 Windows용 한글 패치의 설치·복구 및 제작 도구 소스를 제공합니다. 패치 데이터는 Releases의 ZIP으로 제공합니다.

## 적용 대상 Steam 빌드

- **Steam build ID: `26356968`**
- 게임 내부 `version.txt`: `13480`
- Windows 11, 기본 Windows PowerShell 5.1
- 패치 파일: `queens-domain-ko-26356968-r2.zip`

설치기는 대상 게임 파일의 해시가 일치할 때만 설치합니다. 게임이 업데이트되면 이 패치가 적용되지 않을 수 있습니다.

## 마지막 Releases 이후 패치 업데이트

- 게임 현지화 리소스 2,383개 항목을 영어 원문 및 용어집과 대조해 52개 문구를 다듬었습니다. 뜻이나 사용처를 확인하지 못한 일부 문구는 기존 영어를 유지했습니다.
- 공통 글꼴 리소스에 Hahmlet Bold를 적용하고 일부 게임오버·스틱버그 이미지에 Hahmlet Black을 사용했습니다. 공통 글꼴·이미지·위젯은 다른 언어에도 영향을 주며, 일부 문자가 표시되지 않을 수 있습니다. 글꼴 라이선스는 ZIP 안에 포함되어 있습니다.
- 파일 선택 화면에서 `플레이 시간`과 시간 숫자를 함께 배치해 겹침을 줄이고 글자 하단이 보이도록 조정했습니다.

Windows 11의 독립 사본에서 설치 → 복구·백업 정리 → 재설치를 확인했습니다. 동일한 패치 데이터로 2560×1440 파일 선택 화면의 한 슬롯과 시간값을 확인했으며 겹침이나 잘림을 관찰하지 못했습니다. 기존 후보에서 타이틀·설정·일시정지와 인벤토리 일부도 확인했습니다. **다른 해상도·언어와 전체 게임 진행은 확인하지 않은 프리릴리스입니다.**

확인 중 기존 세이브 파일 9개의 해시는 같았고, CrashReportClient 설정 파일은 한 경로에서 새로 발견되고 다른 한 경로에서 없어졌습니다. 원인과 주체는 확인되지 않았습니다.

## 설치 방법

1. Releases에서 `queens-domain-ko-26356968-r2.zip`을 내려받습니다.
2. 게임과 Steam 업데이트, 모드 관리자 등 게임 파일을 변경할 수 있는 프로그램을 종료합니다.
3. 이전 패치가 설치돼 있다면 이전 버전의 `KoreanPatch/restore.cmd`로 먼저 복구합니다.
4. ZIP 안의 `KoreanPatch` 폴더를 게임 설치 폴더에 넣습니다. `version.txt`와 `KoreanPatch`가 같은 위치에 있어야 합니다.
5. `KoreanPatch/install.cmd`를 실행하고 안내를 확인한 뒤 진행합니다. 설치가 끝날 때까지 창을 닫거나 PC를 끄지 마세요.
6. 게임의 언어 설정에서 **일본어**를 선택합니다. 이 슬롯의 일본어는 한국어로 대체됩니다.

패치를 제거하려면 현재 패치의 `restore.cmd`를 실행하고 복구가 끝날 때까지 기다립니다. 복구가 끝나기 전에 백업이나 상태 파일을 직접 지우지 마세요.

## 소스와 재현 범위

**이 저장소의 소스 파일만으로는 완성된 한글 패치를 재현할 수 없습니다.** 게임 원본 텍스트·이미지와 번역·수정된 리소스 및 패치 PAK는 소스 저장소에 포함하지 않습니다. 해당 자료와 별도의 Unreal 리소스 도구가 필요합니다. Releases ZIP에는 설치에 필요한 패치 데이터가 들어 있습니다.

`scripts/build_package.py`는 별도로 준비한 정확한 패치 PAK와 이 저장소의 설치기·manifest·안내문·글꼴 라이선스로 ZIP을 조립합니다. 제작 소스는 `project/tools/`, 공통 텍스트 검사의 의존 코드는 `toolbox/tools/`에 있습니다. UAssetAPI와 UnrealLocres 등 외부 실행 파일은 제공하지 않습니다.
