# Queen's Domain 한글 패치

Queen's Domain의 메뉴와 게임 텍스트를 한국어로 표시하는 패치입니다.

## 적용 대상

- **Steam build ID: `26496428`** / 게임 버전 `13540`
- Windows 11
- 다운로드 파일: `queens-domain-ko-26496428.zip`

게임이 업데이트되거나 설치된 게임 파일이 지원 대상과 다르면 설치가 중단될 수 있습니다.

## 이번 업데이트

- 이번 게임 업데이트에는 새로 번역할 문구가 없었습니다. 기존 번역은 모두 그대로 유지합니다.
- 도전 과제 화면의 `확인` 문구가 게임 업데이트로 다른 항목을 가리키게 되어 다시 연결했습니다.
- 게임이 파일 선택 화면의 플레이 시간 배치를 직접 고쳐서, 이 패치의 저장 슬롯 수정은 빼고 게임 원본을 그대로 사용합니다.
- 기존 번역, Hahmlet 글꼴과 이미지, 글꼴 줄 높이 조정, 아이템 상세 화면의 오른쪽 회전 안내 수정은 그대로 포함합니다.

이 패치는 **일본어 언어 슬롯을 한국어로 대체합니다.** 공통 글꼴과 일부 이미지를 함께 바꾸므로 다른 언어의 문자가 제대로 표시되지 않을 수 있습니다. 일부 문구는 영어로 남아 있습니다. Hahmlet 글꼴 라이선스는 ZIP에 들어 있습니다.

Windows 11에서 설치 → 복구 → 재설치와 2560×1440 해상도의 타이틀, 파일 선택(저장 슬롯의 플레이 시간), 게임플레이 설정 화면(`화면 흔들림 끄기`)을 확인한 프리릴리스입니다. 도전 과제 화면, 가이드, 아이템 상세, 전원 단말기를 비롯해 다른 화면, 해상도, 언어와 전체 게임 진행은 확인하지 않았습니다.

## 설치 방법

1. Releases에서 `queens-domain-ko-26496428.zip`을 내려받습니다.
2. 게임과 Steam 업데이트, 모드 관리자 등 게임 파일을 변경할 수 있는 프로그램을 종료합니다.
3. 이전 패치가 설치돼 있다면 이전 버전의 `KoreanPatch/restore.cmd`를 먼저 실행해 복구합니다.
4. ZIP 안의 `KoreanPatch` 폴더를 게임 설치 폴더에 넣습니다. `version.txt`와 `KoreanPatch`가 같은 위치에 있어야 합니다.
5. `KoreanPatch/install.cmd`를 실행하고 안내를 읽은 뒤 진행합니다. 설치가 끝날 때까지 창을 닫거나 PC를 끄지 마세요.
6. 게임의 언어 설정에서 **일본어**를 선택합니다.

## 복구와 업데이트

패치를 제거하려면 게임을 종료한 뒤 `KoreanPatch/restore.cmd`를 실행하고 복구가 끝날 때까지 기다립니다. 복구가 끝나기 전에 백업이나 상태 파일을 직접 지우지 마세요. 게임을 업데이트하거나 다른 버전의 패치를 설치할 때도 기존 패치를 먼저 복구하세요.
