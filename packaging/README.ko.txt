Queen's Domain 한국어 패치 — Windows 프리릴리스

대상: Steam build 26663759 / 게임 버전 13571, Windows 11.

이 패치는 게임의 일본어 언어 슬롯을 한국어로 바꿉니다. 설치 후 게임 설정에서 일본어를 선택하세요. 공통 글꼴과 일부 이미지를 함께 변경하므로 다른 언어의 문자가 제대로 표시되지 않을 수 있습니다. 일부 게임 문구는 영어로 남아 있습니다.

이번 버전은 게임 업데이트에 맞춰 도전 과제 화면의 확인 문구를 다시 연결했습니다. 저장 슬롯 화면은 게임 원본을 그대로 사용합니다.

일부 화면에서 확인한 프리릴리스입니다. 다른 해상도와 게임 전체 진행은 아직 확인하지 않았습니다. 게임이 업데이트되거나 게임 파일이 지원 대상과 다르면 설치가 중단될 수 있습니다.

설치
1. 게임과 Steam 업데이트, 모드 관리자 등 게임 파일을 바꿀 수 있는 프로그램을 종료하세요.
2. 이전 패치가 설치되어 있으면 이전 패치의 KoreanPatch/restore.cmd를 먼저 실행해 복구하세요.
3. ZIP의 KoreanPatch 폴더를 게임 폴더 바로 아래에 넣으세요. version.txt와 KoreanPatch 폴더가 같은 위치여야 합니다.
4. KoreanPatch/install.cmd를 실행하고 안내를 확인한 뒤 진행하려면 Y를 입력하세요.
5. 작업이 끝날 때까지 명령 창을 닫거나 PC를 끄지 말고 다른 프로그램이 게임 파일을 바꾸지 않게 하세요.
6. 게임의 언어 설정에서 일본어를 선택하세요.

복구와 업데이트
1. 게임과 관련 프로그램을 종료하고 KoreanPatch/restore.cmd를 실행해 안내를 따르세요.
2. 복구가 끝나기 전에 백업이나 상태 파일을 직접 지우지 마세요. 복구 후 백업 정리만 실패했다면 원인을 해결하고 restore.cmd를 다시 실행하세요.
3. 게임 업데이트나 다른 버전의 패치를 설치하기 전에는 기존 패치를 복구하세요.

복구할 수 없다면 Steam의 파일 검사나 게임 재설치 등으로 원본을 복원하세요. 세이브와 사용자 설정은 직접 삭제하지 마세요.
