Queen's Domain 한국어 패치 — Windows 프리릴리스

이 패치는 Steam판 build 26356968 (version.txt 13480), Windows 11 및 기본 Windows PowerShell 5.1을 대상으로 합니다. 별도의 Python 설치나 다운로드는 필요하지 않습니다. 대상 게임 파일 세 개의 해시가 지정된 원본과 다르면 설치가 중단됩니다.

게임의 일본어 슬롯을 한국어로 대체합니다. 설치 후 게임의 언어 설정에서 일본어를 선택하세요. 기존 일본어 번역은 이 슬롯에서 표시되지 않습니다. 공통 글꼴·이미지·위젯은 다른 언어에도 영향을 주며 일부 문자가 표시되지 않을 수 있습니다.

설치
1. 게임과 Steam 업데이트, 모드 관리자 등 게임 파일을 바꿀 수 있는 프로그램을 종료하세요.
2. 이전 패치가 설치되어 있으면 이전 패치의 KoreanPatch/restore.cmd로 먼저 복구하세요.
3. ZIP의 KoreanPatch 폴더를 게임 폴더 바로 아래에 넣으세요. version.txt와 KoreanPatch 폴더가 같은 위치여야 합니다.
4. KoreanPatch/install.cmd를 실행하고 안내를 확인한 뒤 진행하려면 Y를 입력하세요.
5. 작업이 끝날 때까지 명령 창을 닫거나 PC를 끄지 말고 다른 프로그램이 게임 파일을 바꾸지 않게 하세요.

복구와 업데이트
1. 게임과 관련 프로그램을 종료하고 KoreanPatch/restore.cmd를 실행해 안내를 따르세요.
2. 복구가 끝나기 전에 백업이나 상태 파일을 직접 지우지 마세요. 복구 후 백업 정리만 실패했다면 원인을 해결하고 restore.cmd를 다시 실행하세요.
3. 게임 업데이트나 다른 버전의 패치를 설치하기 전에는 기존 패치를 복구하세요. 충돌이 발견되면 프로그램 안내를 확인하세요.

강제 종료·전원 차단·다른 프로그램의 동시 변경 뒤 자동 복구는 보장되지 않습니다. 복구할 수 없다면 게임 플랫폼의 파일 검사 또는 게임 재설치 등으로 원본을 복원하세요. 세이브와 사용자 설정은 직접 삭제하지 마세요.

글꼴과 검증 범위
게임 글꼴에는 Hahmlet Bold, 일부 게임오버와 스틱버그 이미지에는 Hahmlet Black을 사용합니다. 글꼴 라이선스는 LICENSE-Hahmlet-OFL.txt에 있습니다. 게임 텍스트를 원문 및 용어집과 대조해 52개 문구를 다듬었고 확인이 어려운 일부 문구는 영어로 유지했습니다.

Windows 11의 독립 사본에서 같은 패치 데이터와 설치기의 설치·복구·재설치를 확인했습니다. 2560×1440 파일 선택 화면에서 한 슬롯의 플레이 시간과 숫자 표시를 확인했습니다. 다른 해상도·언어와 전체 게임 진행은 확인하지 않았습니다.

시험 중 세이브 파일 9개의 해시는 같았으나 CrashReportClient 설정 파일은 한 경로에서 새로 나타나고 다른 한 경로에서 없어졌습니다. 원인과 주체는 확인되지 않았습니다.
