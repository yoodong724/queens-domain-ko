Queen's Domain 한국어 패치 — Windows (부분 검증)

이 패치는 게임의 일본어 슬롯을 한국어로 바꿉니다. 대상은 Steam판 build 26356968 (version.txt 13480), Windows 11 및 기본 Windows PowerShell 5.1입니다. 실행에 별도 Python 설치나 다운로드는 필요하지 않습니다. 지원 여부를 확인하는 게임 파일 세 개가 지정된 원본과 다르면 설치가 중단됩니다.

게임의 일본어 슬롯을 한국어로 대체합니다. 설치 후 게임의 언어 설정에서 일본어를 선택하세요. 기존 일본어 번역은 이 슬롯에서 표시되지 않으며, 공통 이미지와 위젯은 다른 언어에도 영향을 줄 수 있습니다.

설치
1. 게임과 런처 업데이트, 모드 관리자 등 게임 파일을 바꿀 수 있는 프로그램을 종료하세요.
2. ZIP의 KoreanPatch 폴더를 게임 폴더 바로 아래에 넣으세요. version.txt와 KoreanPatch 폴더가 같은 위치여야 합니다.
3. KoreanPatch/install.cmd를 실행하고 경고를 읽은 다음 진행하려면 Y를 입력하세요.
4. 작업이 끝날 때까지 명령 창을 닫거나 PC를 끄지 말고 다른 프로그램이 게임 파일을 바꾸지 않게 하세요.

이전 후보가 설치되어 있으면 이전 후보의 restore.cmd로 먼저 복구한 뒤 이 후보를 설치하세요.

복구와 업데이트
1. 게임과 관련 프로그램을 종료하고 KoreanPatch/restore.cmd를 실행해 안내를 따르세요.
2. 복구가 끝나기 전에 백업이나 상태 파일을 직접 지우지 마세요. 복구 후 백업 정리만 실패했다면 원인을 해결하고 restore.cmd를 다시 실행하세요.
3. 게임 업데이트나 다른 버전의 패치를 설치하기 전에는 기존 패치를 복구하세요. 충돌이 발견되면 프로그램 안내를 확인하세요.

강제 종료·전원 차단·다른 프로그램의 동시 변경 뒤 자동 복구는 보장되지 않습니다. 복구할 수 없다면 게임 플랫폼의 파일 검사 또는 게임 재설치 등으로 원본을 복원하세요. 세이브와 사용자 설정은 직접 삭제하지 마세요.

검증 상태: 13480 원본의 패치 대상 리소스 14개와 영어 현지화 리소스는 이전 13471 빌드와 바이트 단위로 같습니다. 이전 13471 패키지의 Windows 설치·복구 시험과 이전 게임 화면 확인은 13480의 시험 결과가 아닙니다. 이 빌드의 실제 게임 표시·글꼴과 전체 게임 진행은 확인하지 않았습니다. 공통 이미지와 위젯이 다른 언어에 미치는 영향도 전체 확인하지 않았습니다.
